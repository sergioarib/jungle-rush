# Jungle Rush 🛩️🌴

**Jungle Rush** is a 3D endless runner arcade game built with Unity. Take control of a military ship navigating through a dark, dense jungle while dodging ancient overgrown stone pillars and collecting coins to achieve the highest possible score.

---

### 🎮 Game Overview & Features

- **Endless Gameplay:** Procedurally increasing challenge as you fly deeper into the jungle.
- **Dynamic Obstacles:** Dodge massive, ivy-covered stone ruins blocking your flight path.
- **Score System:** Earn points over time and collect bonus coins positioned over lower pillars.
- **Atmospheric Visuals:** Stylized dark jungle environment paired with a military aircraft model.

---

### 🛠️ Built With

- **Engine:** Unity 3D
- **Language:** C#
- **Target Platform:** WebGL / Windows Standalone

---

### 🕹️ How to Play

1. **Steer:** Use `W` / `A` / `S` / `D` or `Up` / `Left` / `Down` / `Right` Arrow keys to maneuver the ship.
2. **Goal:** Survive as long as possible, avoid colliding with stone pillars, and collect bonus coins to maximize your score.
